# WebSocket 接收路由

> 服务器 → 客户端。`socket.__onmessage(e)` 的顶级 `switch (e[0])` 按**首字符**分发。消息字段以 `>` 分隔（有些用 `"`）。

| `~` | 媒体列表 |
| `^` | 用户搜索结果 |
| `:` | 动态 / 任务 / 论坛 / 编辑 |

## 聊天消息（`"`）

### 公屏

**原始内容：**

```
"时间>头像>用户名>内容>mc>nc>性别>>uid>rank'装备'用户json>消息id
```

**内容解析：**

```
"(时间戳秒)>(头像URL)>(昵称)>(消息文本)>(消息颜色RGB)>(名字颜色)>(性别M/F/G)>>(uid)>(等级'装备')(用户json)>(消息id)
```

> `消息id` 用于撤回；`uid` 与后面字段之间是**两个 `>`**（中间空位）。

### 私聊

**原始内容：**

```
""时间>uid>用户名>头像>内容>mc>类型>名字颜色>性别>头像大图>标记>消息id
```

**内容解析：**

```
""(时间戳)>(uid)>(用户名)>(头像)>(内容)>(消息颜色)>(类型)>(名字颜色)>(性别1/2)>(头像大图)>(标记)>(消息id)
```

> 前缀**两个 `"`** 区分公屏/私聊。`类型` 空=普通、`@`=匿名；`性别` 1=♂ 2=♀。自己发的消息尾部额外追加发送者信息段；一次可能合并多条私聊，每条以 `>` 分隔。

### 消息渲染要点

- 引用：`旧内容 (_hr) 发送者_消息id (hr_) 新内容`
- @用户：`[*用户名*]`（两侧空格）
- 匿名：`st:"@"`
- 特殊命令：`/webcam1` `/webcam2`（视频/音频通话，WebRTC，P2P 信令走 `?` 前缀）

## 房间数据（`%`）

**原始内容：**

```
%房间id"房间内容
```

**内容解析：**

```
%(房间id)"(房间数据)
```

> `%*房间id"...` 为银行/股票数据 + 房间刷新；`%a` 表示当前房间；密码房 `%*密码"..."` 校验。

## 切房 / 密码房（`m` 与 `` `~ ``）

移动房间分两步：密码房先发询问包验密码，再发移动包；服务端分别回对应结果码。

**原始内容：**

```
=^~65cc3d4e2f26f>iirosebot
m6547d48b60b2b
```

**内容解析：**

```
=^~(目标房间id)>(房间密码)
m(目标房间id)
```

| 回包 | 含义 |
|---|---|
| `` `~1 `` | 密码正确，可继续移动 |
| `` `~0 `` | 密码错误 |
| `m` | 允许移动 |
| `m!5` | 未提供密码 |

> 移动成功后需断开 WS，重新发送登录包把 `r` 改成目标房间，并带上 `lr`（旧房间 id）和 `rp`（目标房间密码，用完即删）。

## whois（`+`）

**原始内容：**

```
+<房间名>在线用户列表
```

**内容解析：**

```
+(房间名)(在线用户列表)
```

> 用于展示房间在线用户（`Variable.whoisArr`）。请求：`socket.send("+@房间名")`。

## 弹幕（`=`）

**原始内容：**

```
=用户名>内容>mc>nc>性别>头像>时间>uid
```

**内容解析：**

```
=(用户名)>(内容)>(消息颜色)>(名字颜色)>(性别)>(头像)>(时间)>(uid)
```

## 系统通知（`_`）

按 `e[2]` 二级命令：

| 二级 | 含义 |
|---|---|
| `_0`-`_3` | 余额/奖励（`_3` 送 1 万币） |
| `_p`/`_q` | 私聊相关通知 |
| `_l` | 未读通知 |
| `_!`/`_@`/`_#` | 房内发言/点播限制 |
| `_$` | 被禁言/禁点播（`_$名>时长>原因>类型`） |
| `_%`/`_w` | 黑名单 / 白名单 |
| `_^` | 解除限制 |
| `_r`/`_x` | 其他通知 |
| `__` | console 日志 |

## 房内限制（`.`）

| 二级 | 含义 | 等级映射 |
|---|---|---|
| `.!/` | 发言限制 | 0所有人/1普通+/2带星+/3仅房主/4白名单+/5仅白名单 |
| `.@` | 点播限制 | 同上 |
| `.#` | 发言+点播限制 | — |

## 其他

- `~` 媒体列表、`^` 用户搜索、`:` 动态/任务/论坛、`,` 媒体 seek、`;` 预填输入：均在各自面板处理器中解析
- `Tk`/`Te`/`Ta`：加密币 / 美股 / A股行情，进房时 `%` 数据里带，后续推送更新
