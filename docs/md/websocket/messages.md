# WebSocket 接收路由

> 服务器 → 客户端。`socket.__onmessage(e)` 的顶级 `switch (e[0])` 按**首字符**分发。消息字段以 `>` 分隔（有些用 `"`）。

## 聊天消息（`"`）

### 公屏

```
"时间>头像>用户名>内容>mc>nc>性别>>uid>rank'装备'用户json>消息id
```

| 字段 | 说明 |
|---|---|
| 时间 | 时间戳（秒） |
| 头像 | 头像 URL |
| 用户名 | 昵称 |
| 内容 | 消息文本 |
| mc | 消息颜色 RGB |
| nc | 名字颜色 |
| 性别 | `M`/`F`/`G` |
| uid | 用户 id |
| rank'装备' | 等级 + 装备信息 |
| 用户json | 用户信息（性别/头像等） |
| 消息id | 消息唯一 id（用于撤回） |

### 私聊

```
""时间>uid>用户名>头像>内容>mc>类型>名字颜色>性别>头像大图>标记>消息id
```

- 前缀 **两个 `"`** 区分公屏/私聊
- 字段（L13137 `privatechatfunc` 解析）：`时间`=秒级时间戳、`uid`、`用户名`、`头像`、`内容`、`mc`=消息颜色(6位hex)、`类型`（空=普通，`@`=匿名）、`名字颜色`=nc、`性别`（1=♂ 2=♀）、`头像大图`、`标记`（在线状态等）、`消息id`
- 自己发送的消息（`uid==自身`）尾部额外追加发送者信息段（名字/uid/mc/性别/nc）
- 一次可能合并多条私聊，每条以 `>` 分隔拼接

### 消息渲染要点

- 引用：`旧内容 (_hr) 发送者_消息id (hr_) 新内容`
- @用户：`[*用户名*]`（两侧空格）
- 匿名：`st:"@"`
- 特殊命令：`/webcam1` `/webcam2`（视频/音频通话，走 WebRTC，P2P 信令走 `?` 前缀）

## 房间数据（`%`）

```
%房间id"房间内容
```

- `%*房间id"...`：银行/股票数据 + 房间刷新（`%*` 特殊格式）
- `%a` 表示当前房间
- 密码房间：`%*密码"..."` 校验

## whois（`+`）

```
+<房间名>在线用户列表
```

- 用于展示房间在线用户（`Variable.whoisArr`）
- 请求：`socket.send("+@房间名")`

## 弹幕（`=`）

```
=用户名>内容>mc>nc>性别>头像>时间>uid>...
```

## 系统通知（`_`）

按 `e[2]` 二级命令：

| 二级 | 含义 |
|---|---|
| `_0`-`_3` | 余额/奖励（`_3` 送 1 万币） |
| `_p`/`_q` | 私聊相关通知 |
| `_l` | 未读通知 |
| `_!`/`_@`/`_#` | 房内发言/点播限制 |
| `_$` | 被禁言/禁点播（`_$名>时长>原因>类型`） |
| `_%`/`_w` | 黑名单 / 白名单 |
| `_^` | 解除限制 |
| `_r`/`_x` | 其他通知 |
| `__` | console 日志 |

## 房内限制（`.`）

| 二级 | 含义 | 等级映射 |
|---|---|---|
| `.!/` | 发言限制 | 0所有人/1普通+/2带星+/3仅房主/4白名单+/5仅白名单 |
| `.@` | 点播限制 | 同上 |
| `.#` | 发言+点播限制 | — |

## 其他

- `~` 媒体列表、`^` 用户搜索、`:` 动态/任务/论坛、`,` 媒体 seek、`;` 预填输入：均在各自面板处理器中解析
- `Tk`/`Te`/`Ta`：加密币 / 股票 / 中华币行情，进房时 `%` 数据里带，后续推送更新

## 二级命令完整提取

提取自 `socket.__onmessage` switch（含二级），原始数据见 `extract_output.json`：

```
T  k/e/a（行情）      %  （房间）       +  （whois）
-  */#/-/k/--/---    =  （弹幕）       $  （认证）
&  （共享媒体）        ?  （P2P）        ~  （媒体列表）
^  （用户搜索）        :  */+/-/=/%/^/!（动态/任务/论坛）
.  !/@/#（限制）      ,  （seek）       ;  （预填）
_  0-3/p/q/l/r/x/!/@/#/=/$/%/w/^...（系统通知）
```
