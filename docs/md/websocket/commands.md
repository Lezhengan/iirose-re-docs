# WebSocket 发送命令

> 客户端 → 服务器。所有命令为**明文文本**，首字符为协议前缀（部分为 JSON）。`socket.send(...)` 直接调用。

## 聊天消息（JSON）

| 场景 | 报文 | 说明 |
|---|---|---|
| 群聊公屏 | `{"m":"内容","mc":"颜色","i":"唯一id"}` | 在房间广播 |
| 私聊 | `{"g":"对方uid","m":"内容","mc":"颜色","i":"唯一id"}` | `g` 指向目标用户 uid |
| 引用回复 | 内容中 `旧内容 (_hr) 发送者_消息id (hr_) 新内容` | 引用语法 |
| @用户 | `[*用户名*]`（两侧需空格） | 特殊 @ 语法 |
| @频道 | `[_频道id_]` | 频道 @ 语法 |
| 匿名消息 | 附加 `"st":"@"` | 匿名发言 |

完整发送字段：`{ g: 房间id或uid, m: 内容, mc: 颜色, nc: 名字颜色, se: 性别, uid: 发送者uid, st: 类型, i: 消息唯一id }`

## 弹幕

```
~{"t":"内容","c":"颜色","v":0}
```

（`~` + JSON；需绑定手机且房间允许）

## 进房 / 切房

| 命令 | 功能 |
|---|---|
| `*{JSON}` | **进入房间**（`fetchroom`，L23733）：`socket.send("*" + JSON.stringify(s))`。字段：`r`=房间id、`n`=昵称、`p`=密码、`st`=状态、`mo`=心情、`mb/mu/rp/nt`=杂项、`ros/roi/ron`=角色扮演（可选）、`fp`=指纹（`@`+32位随机串）；登录态另带 `lr`=上次房间、`i`=头像、`nc`=名字颜色、`s`=性别、`uid`、`li`=loginid、`la`=语言 |
| `m房间id` | **切换房间**（登录后，L23620 `socket.send("m" + t ...)`，密码房 `m房间id>密码`） |

> `%房间id` 不是进房命令——`%` 前缀是**服务器推送**房间数据（接收路由，见 [接收路由](messages.md)）；发送 `%` 仅用于请求媒体列表（`@` 快捷命令，L2874）。

## 点播 / 共享媒体

> 点播只允许在**共享媒体房间**（`mediaShareRoom`）操作，入口是 `<>` 分享 / `@@ 歌名` 直搜直发 / `@ 歌名` 搜索面板 / 侧边栏 `@` 按钮。发送方式分两类：**视频直连命令**（`dv` 前缀）与 **点播卡片消息**（`m__4` 格式）。

### 1. 视频直连命令（`dv` 前缀）

| 命令 | 平台 | 参数说明 |
|---|---|---|
| `dv0{视频id}` | 爱奇艺 | id 从 `curid=` 或 `iqiyi.com/v_` 提取 |
| `dv1{视频id}` | 腾讯视频 | id 从 `x/cover/`、`x/page/`、`play.html?coverid=` 提取 |
| `dv3{id}#{分P}` | B站 | id 可为 BV 号、av 号、番剧 `ss…`、课程 `_…`；`#` 后为分 P（可空） |

```js
// 点播 B站视频（BV 号 + 分 P）
socket.send("dv3BV1xxxx#1");

// 点播爱奇艺
socket.send("dv0" + "视频id");

// 点播腾讯视频
socket.send("dv1" + "视频id");
```

> B站**直播**不走 dv：前端本地模拟接收 `socket._onmessage("t18{名字}>{作者}>{封面}>>{播放地址}>>30>")` 渲染卡片 + `Utils.setPlayerSrc` 直接播放（L3107）。

### 2. 点播卡片消息（`m__4` 格式，音乐）

音乐点播发送的是**群聊消息**，`m` 字段以 `m__4` 开头（接收端识别后转为 `'4` 系统消息，渲染成 `.systemCardMediaShare` 卡片，见 L14130/`Mod.demandCard` L9473）：

```
m__4@{平台}>{名字}>{作者}>{封面}>{主题色}>{码率}
```

- `@`=音乐卡片；`*`=视频卡片（同格式）
- 平台索引：`0`=网易云、`2`=QQ、`3`=太合、`4`=酷狗（其余见 `Assets.iconAudio` 下标）
- 数据段用 `>` 分隔（传输中为 HTML 实体 `&gt;`）
- 老式简版：`m__4!{平台}>{名字}>{作者}`（视频）、`m__4%{平台}>{名字}>{作者}>{封面}`（带封面音乐）

接收端子类型（`m__4` 后第 3 字符，L14138-14160）：`@`音乐卡、`=`音乐卡带封面、`%`音乐卡带封面(变体)、`#`视频卡、`*`视频卡带封面、`!`视频卡带封面(变体)。

### 3. 内部文本点播（不用 WS 解析接口）

```js
// ① 分享文本：<> + 链接 + "名字"封面"作者（空格或直接拼接）
Utils.service.moveinputDo('<> https://music.163.com/#/song?id=xx"告白气球"http://r.iirose.com/i/...jpg"周杰伦');

// ② 搜索直发（网易云 @@ 歌名：直接搜取【第一首】播放发送，L2883）
//    等价于调 search_163Music.php → result.songs[0] → 自动拼 <> 链接
Utils.service.moveinputDo("@@ 告白气球");

// ③ 打开媒体搜索面板（@ 歌名：弹搜索结果列表，需手动点选，L2908）
//    仅媒体分享房间可用；默认切到"音频"搜索页并自动填入关键词执行搜索
Utils.service.moveinputDo("@ 告白气球");

// ④ 官方统一入口 demandSend(类型, 平台, 名字, 作者, 播放地址, 封面, 原链接, 码率, 歌词)（L12393）
//    本地立即播放 + 发送 m__4@ 卡片
demandSend(0, 0, "告白气球", "周杰伦",
  "https://music.163.com/song/media/outer/url?id=xx",
  "封面图URL", "s://music.163.com/#/song?id=xx", 128, "歌词");

// ⑤ 直接发送点播卡片（绕过 UI，效果同 ④ 的发送部分）
socket.send(JSON.stringify({
  m: "m__4@0>告白气球>周杰伦>封面图URL>6B5A4E>128",
  mc: "255,255,255",
  i: "id_" + Date.now()
}));
```

> ② `@@` 与 ③ `@` 的区别：`@@ 歌名` 直接请求 `search_163Music.php` 并**自动取第一首**发到房间；`@ 歌名`（或 `@歌名`）打开 `demandHolder` **搜索面板**（槽位 17，`d.function.search(0)`）显示结果列表手动选择。两者都要求媒体分享房间（`mediaShareRoom`），且优先走当前房间默认媒体引擎（非网易云平台在面板里切引擎）。
> 关键词与 `@@`/`@` 之间**空格可有可无**（源码 `e.substr(2).trim()` 处理，L2883/L2909）。细微差别：`@ 歌名`（带空格）默认切"歌单列表"tab，`@歌名`（无空格）默认"音频"tab（L2921）。

> ⚠️ 注意：往输入框**手动敲** `m__4…` 会被 `Utils.Filter.pubMsg`（L2251）自动加上不可见字符前缀，防止伪造系统/点播消息；用 `socket.send` 或 `demandSend` 则不受此限制。
> 分享文本格式 `<> url"名字"封面"作者` 由源码自动构造（`@@` 搜索后 L2888），名字与封面之间是两个 `"`。

### 服务端推送解析（`case "T"` 路由 → `exchangeFn(P).onMsg`，L17818）

接收端 L13353 按 `e[1]` 分发到 `cryptoHolder`/`stockHolder`/`chinaHolder` 的 `.function.onMsg(e)`，`e[2]` 为子命令、`e.substr(3)` 为数据体。字段多以 `"` 分隔条目、条目内逗号分隔：

| 子命令 | 含义 | 数据格式（`"` 分隔） |
|---|---|---|
| `S` | **市场状态** | `1`=盘中、`2`=盘前、`3`=盘后、其它=休市（A股另算时段，只分盘中/休市） |
| `#` | **全量行情列表** | 每条 `代码,名称,现价,昨收,价格精度,数量精度,今开[,涨停,跌停]` → `Variable.coins` |
| `P` | **实时价格推送** | `代码"现价"昨收""今开`（`updatePx`，L17097） |
| `c` | 花钞余额更新 | 数字 |
| `H` | **持仓全量** | 每条 `代码,数量[,今日数量]` → `Variable.hold` |
| `B`/`E` | 买入/卖出成交 | 见 `onTrade`（L17108） |
| `O` | 合约仓位全量 | 每条 `id,方向,币种,数量,开仓价,杠杆,保证金,强平价[,资金费,止盈,止损]` |
| `L`/`C` | 开仓 / 平仓确认 | `onOpen`/`onClose` |
| `!` | 实时爆仓 | `仓位id"币种"保证金` |
| `R` | 离线期间爆仓通知 | 多条 `仓位id,币种,保证金` |
| `K` | **K线数据** | `代码"周期"` + `;` 分隔的 `开,高,低,收` 段 → `Variable.chartBars`（canvas 绘制） |
| `w`/`n` | 二元期权开 / 结算 | `onBinaryOpen`/`onBinarySettle` |
| `Z`/`N` | 二元期权全量 / 离线通知 | — |
| `T`/`u` | 标准期权开 / 结算 | `onOptionOpen`/`onOptionSettle` |
| `U`/`M` | 标准期权全量 / 离线通知 | — |
| `G`/`g` | 签到状态 / 签到结果 | `G`: `今日已签,连续,奖励`；`g`: `奖励,连续,累计,余额` |
| `A`/`X` | 预警设置成功 / 删除 | — |
| `V`/`W` | 预警全量 / 触发通知 | — |
| `h` | 历史记录回包 | 类型 + 条目（`renderHistList`） |
| `Y`/`D` | 止盈止损更新 / 离线触发 | — |
| `F`/`x`/`i`/`j` | 限价委托挂单 / 撤单 / 成交 / 全量 | — |
| `S`/`I`/`J` | 理财存入 / 赎回 / 全量 | — |
| `Q`/`q` | 排行榜 / 今日战绩 | — |
| `v` | 交易统计回包 | `renderStats`（总盈亏/胜率/回撤等 10 项） |

### 数据存储与渲染

- 行情对象：`Objs.{crypto|stock|china}Holder.Variable.coins[代码] = { name, coin(现价), prev(昨收), pd(价格精度), qd(数量精度), open(今开), up/dn(A股涨跌停) }`（L17942）
- 自选收藏：localStorage `stockFav` / `cryptoFav` / `chinaFav`（JSON 数组，L16995）
- 面板 UI 记忆：localStorage `stockUI` / `cryptoUI` / `chinaUI`（页签/排序/K线周期等，L17853）
- 涨跌颜色 class：`crUp`/`crDn`（CSS 变量 `--cu`/`--cd`），面板右上角齿轮可切换"红涨绿跌"（Cookie `crColorRev_面板id`）
- 价格精度：`formatThousand`（千分位），`≈$现价/180`（美股）/`≈¥现价/25`（A股）折算参考（L17186）

### 静态资源（唯一 HTTP 请求）


### 默认入口："炒股"面板（`stockOldHolder`）

花园侧边栏「消费」分组里默认可见的**"炒股"按钮** `functionBtnDo(9)` 打开的是**旧版**面板（`Init.movePanel(0)`，L18050，面板槽位 `panelAnimate(26)`），**数据不走 `T` 协议**，而是包含在房间载荷 `%*` 推送里（L13361）：`"` 分隔的数据段内以 `#` 分隔银行与股票数据，股票部分再用 `$` 分隔价格字段，由 `Objs.stockOldHolder.function.stockUpdate(...)`（L18069）解析渲染"总市值 / 现价 / 涨跌"。功能很简单（现价/买入/卖出）。

## 播放媒体（`&` 命令）

> 分享/播放媒体的**直接通道**（非点播卡片消息，本地接收端 L13390 `case "&"` → `shareMedia`）。由 `demandSend` 或 `<>` 分享文本解析后发送。前端 `&` 后跟 JSON；`&1` = 视频分享房、`&0` = 其他房（iirosebot `play_media` 的判断：`mediaShareRoom` 属性为 `video_share` 用 `&1`，否则 `&0`）。

```
&0{ "s": 播放地址, "d": 时长秒, "c": 封面图, "n": 名字, "r": 作者, "b": 平台标识, "o": 原链接, "l": 歌词 }
```

`b` 平台标识（iirosebot `api_iirose.py`）：

| 值 | 平台 |
|---|---|
| `@0` | 网易云 |
| `@2` | QQ 音乐 |
| `@4` | 酷狗 |
| `!3` | B站视频 |
| `!8` | B站直播 |
| `=0` / `=1` | 通用音频 / 视频 |

```js
// 播放网易云歌曲（时长可本地 ffprobe 探测）
socket.send("&0" + JSON.stringify({
  s: "https://music.163.com/song/media/outer/url?id=xx",
  d: 215, c: "封面URL", n: "告白气球", r: "周杰伦",
  b: "@0", o: "s://music.163.com/#/song?id=xx", l: "歌词"
}));
```

切歌控制见命令族表 `{0-3` 行（`{0`=投票切歌，`send_msg`+`{0` JSON 消息体）。

## 房主管理命令（`!` 前缀）

> 房间管理操作，参数为 JSON 数组字符串（`["..."]`）。来自 [iirosebot](https://github.com/XCWQW1/iirosebot) `api_iirose.py`（`send_notice`/`send_kick`/`send_ban`）。

| 命令 | 功能 | 格式 |
|---|---|---|
| `!!["公告"]` | 发房间公告 | `socket.send('!!["' + msg + '"]')` |
| `!#["用户名"]` | 踢人（用户名需小写） | `socket.send('!#["' + 用户名小写 + '"]')` |
| `!h3["41","用户名","时长s","原因"]` | 禁言（按用户名+时长） | `socket.send('!h3["41","' + 用户名小写 + '","' + 时长 + 's","' + 原因 + '"]')` |
| `!h3[…]` 变体 | 全员禁言（`whole_ban`） | 同类 JSON 参数（enable 开关） |

## 论坛发帖（`:-` 前缀）

```
:-{"t": "内容（可带颜色前缀）", "r": "随机消息id"}
```

- 非认证用户（游客）无法发送
- `r` 为回复目标 id（回复时填），`t` 可拼颜色 + `[@回复id]`（iirosebot `send_msg_to_forum`）

## Markdown 消息

消息内容以 `\\\*` + 换行开头即按 **Markdown** 渲染（接收端识别 markdown 前缀，`markDownBox` 容器）：

```
\\\*
# 标题

**加粗**、`代码`

普通文本
```

- 代码块：`\\\*` + 换行 + ` ```lang ` + 代码 + ` ``` `
- 示例（iirosebot `api_message.py`）：`send_markdown(md)` = `f"\\\*\n{md}"`，`send_markdown_code(code, lang)` = `f"\\\*\n```{lang}\n{code}\n```"`
- 配合 `at_user(name)` = ` [*用户名*] `、`room_address(rid)` = ` [_{房间id}_] ` 可拼接
