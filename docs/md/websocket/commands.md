# WebSocket 发送命令

> 客户端 → 服务器。所有命令的**业务载荷为明文文本**，首字符为协议前缀（部分为 JSON）。`socket.send(...)` 直接调用。注意：底层 WebSocket 帧采用**二进制封装**（`binaryType='arraybuffer'`），> 256 字节的载荷会 gzip 压缩并加首字节 `0x01` 标记（详见 [transport.md](md/websocket/transport?id=帧编码)），但这里列出的命令均为**压缩前**的明文格式。

> 面向第三方机器人的**精简命令速查**见 [third-party.md](md/websocket/third-party.md)（含 adapter-iirose 交叉验证、连接地址、登录包、心跳与完整接收解析）。

## 聊天消息（JSON）

发往房间 / 私聊的都是一个 JSON 字符串，`m` 是正文、`mc` 是消息颜色、`i` 是消息唯一 id。

### 群聊公屏

**原始内容：**

```
{"m":"大家好","mc":"255,255,255","i":"859295709937"}
```

**内容解析：**

```
{"m":"(消息内容)","mc":"(消息颜色)","i":"(随机id)"}
```

### 私聊

比公屏多一个 `g`，指向对方 uid：

**原始内容：**

```
{"g":"5b0fe8a3b1ff2","m":"你好","mc":"040b02","i":"492977760202"}
```

**内容解析：**

```
{"g":"(对方uid)","m":"(消息内容)","mc":"(消息颜色)","i":"(随机id)"}
```

### 正文里的特殊语法

| 写法 | 效果 |
|---|---|
| `旧内容 (_hr) 发送者_消息id (hr_) 新内容` | 引用回复 |
| `[*用户名*]`（两侧空格） | @用户 |
| `[_频道id_]` | @频道 |

> 附加 `"st":"@"` 可发匿名消息；完整字段还有 `nc`(名字颜色)、`se`(性别)、`uid`(发送者)、`st`(类型)，非必需。

## 弹幕

**原始内容：**

```
~{"t":"大家好","c":"040b02","v":0}
```

**内容解析：**

```
~{"t":"(消息内容)","c":"(消息颜色)","v":0}
```

> `~` + JSON；需绑定手机且房间允许。

## 进房 / 切房

### 进入房间

**原始内容：**

```
*{"r":"房间id","n":"昵称","p":"密码","st":"状态","fp":"指纹"}
```

**内容解析：**

```
*{"r":"(房间id)","n":"(昵称)","p":"(密码)","st":"(状态)","fp":"(指纹)"}
```

> 必填 `r/n/p/st`；可选 `mo`=心情、`mb/mu/rp/nt`=杂项、`ros/roi/ron`=角色扮演。登录态另带 `lr`=上次房间、`i`=头像、`nc`=名字颜色、`s`=性别、`uid`、`li`=loginid、`la`=语言。`fp`（指纹）：**官方前端用 `@`+32 位随机串**，第三方 bot（如 adapter）用 `@`+md5(用户名)。

### 切换房间

**原始内容：**

```
m房间id
```

**内容解析：**

```
m(目标房间id)
```

> 密码房：`m房间id>密码`。`%房间id` 不是进房命令——`%` 前缀是服务器**推送**房间数据（见 [接收路由](md/websocket/messages.md)）；发送 `%` 仅用于请求媒体列表。

## 房间 / 商店（`=` 前缀）

| 命令 | 功能 |
|---|---|
| `=^v^` | 请求公告 |
| `=^v#` | 订阅房间列表 |
| `=^v!` | 房间信息（资料）请求 |
| `=^v@` | 房间订阅者列表 |
| `=^v$0房间id` / `=^v$1房间id` | 取消订阅 / 订阅房间 |
| `=^++` | 房子成员添加（房主） |
| `=^+_uid` | 房子成员移除（房主） |
| `=^*^` / `=^*#` / `=^*!` / `=^*@` | 商店「我的房子」页切换（家/社区/旅馆/沙盒） |
| `=^~房间id>密码` | 密码房间进入（先登记密码再 `m` 切房） |
| `=$` | 店铺列表 |
| `=-` | 财富/榜单 |
| `=*0` / `=*1名字` | 清除 / 设置商店排行名 |
| `=~1X` | 商店面板分页请求（`X`=tab：0 装扮、1 排行、2 房子、3 抽奖等） |

## 社交（`+` / `)` / `f` 前缀）

| 命令 | 功能 |
|---|---|
| `+@房间名` | whois 在线列表（房间名小写） |
| `+*uid 备注` | 点赞 |
| `+!uid` | 点踩 |
| `+#0uid` / `+#1uid` | 关注 / 取关 |
| `+_*uid 分数` | 打分（`+_*uid !` 删除） |
| `)#` | 联系人列表 |
| `f@` | 请求目标用户资料（打开面板时发送，通常后接 uid） |

### f/g 店铺管理命令族

> `f` 为「我的店铺」面板、`g` 为「商店」面板，两套命令对称。

| 功能 | f 命令 | g 命令 | 说明 |
|---|---|---|---|
| 卖家中心 | `f+` | `g+` | 打开卖家中心 |
| 店铺首页 | `f^` | `g^` | 店铺总览 |
| 订单 tab | `fu0`~`fu5` | `gu0`~`gu5` | 待付款/待发货/待确认/待评价/已完成/售后 |
| 我的店铺 | `f%` | `g%` | 店铺信息 |
| 店铺数据 | `f;` | `g;` | 统计图表 |
| 待处理订单 | `fo0`~`fo5` | `go0`~`go5` | 卖家视角订单 |
| 店铺粉丝 | `f\|` | `g\|` | 粉丝列表 |
| 分页翻页 | `fg`+页码 | `g_`+页码 | 列表分页 |
| 操作 | `fx`/`fl`/`fn`/`fk`/`fw`/`fe`/`fq`/`fd`/`fD`/`fC`/`fr` | `gx`/`gl`/`gn`/`gk`/`gw`/`ge` | 改价/上架/下架/发货/评价/退款/删除/上首页/评论/获取订单 |
| 快速刷新 | `gf` | — | 已打开 mallHolder 时刷新 |

> 按用户名查资料：adapter 用 `+-username`；官方前端 `userSearchHolder` 用 `=-+`+小写用户名。实现时以实测为准。

## 撤回 / 删除

**原始内容：**

```
v0#消息id
v0*uid#消息id
```

**内容解析：**

```
v0#(消息id)          → 撤回频道消息
v0*(对方uid)#(消息id) → 撤回私聊消息
```

> `v1…` 是私聊撤回变体；`dv0/dv1/dv3` 是点播命令（见下节），不是撤回。

## 点播 / 共享媒体

> 点播只允许在**共享媒体房间**（`mediaShareRoom`）操作，入口：`<>` 分享、`@@ 歌名` 直搜直发、`@ 歌名` 搜索面板、侧边栏 `@` 按钮。

### 1. 视频直连命令（`dv` 前缀）

| 命令 | 平台 | id 提取位置 |
|---|---|---|
| `dv0{视频id}` | 爱奇艺 | `curid=` 或 `iqiyi.com/v_` |
| `dv1{视频id}` | 腾讯视频 | `x/cover/`、`x/page/`、`play.html?coverid=` |
| `dv3{id}#{分P}` | B站 | BV 号 / av 号 / 番剧 `ss…` / 课程 `_…`；`#` 后为分 P（可空） |

```js
socket.send("dv3BV1xxxx#1");   // 点播 B站视频（BV 号 + 分 P）
socket.send("dv0" + "视频id");  // 点播爱奇艺
socket.send("dv1" + "视频id");  // 点播腾讯视频
```

> B站**直播**不走 dv：前端本地模拟接收 `t18{名字}>{作者}>{封面}>>{播放地址}>>30>` 渲染卡片并直接播放。

### 2. 点播卡片消息（`m__4` 格式）

音乐点播发送的是**群聊消息**，`m` 字段以 `m__4` 开头（接收端识别后转成 `'4` 系统消息渲染成卡片）：

**原始内容：**

```
m__4@0>告白气球>周杰伦>封面URL>6B5A4E>128
```

**内容解析：**

```
m__4@(平台)>(名字)>(作者)>(封面)>(主题色)>(码率)
```

> `@`=音乐卡片、`*`=视频卡片；平台索引 `0`=网易云、`2`=QQ、`3`=千千、`4`=酷狗（其余见 `Assets.iconAudio`）。数据段用 `>` 分隔（传输中为 HTML 实体 `&gt;`）。

| 子类型 | 卡片 |
|---|---|
| `@` | 音乐卡 |
| `=` | 音乐卡带封面 |
| `%` | 音乐卡带封面（变体） |
| `#` | 视频卡 |
| `*` | 视频卡带封面 |
| `!` | 视频卡带封面（变体） |

老式简版：`m__4!{平台}>{名字}>{作者}`（视频）、`m__4%{平台}>{名字}>{作者}>{封面}`（带封面音乐）。

### 3. 内部文本点播

```js
// ① 分享文本：<> + 链接 + "名字"封面"作者
Utils.service.moveinputDo('<> https://music.163.com/#/song?id=xx"告白气球"http://r.iirose.com/i/...jpg"周杰伦');

// ② 搜索直发（@@ 歌名：取第一首直接发）
Utils.service.moveinputDo("@@ 告白气球");

// ③ 打开搜索面板（@ 歌名：弹结果列表手动选）
Utils.service.moveinputDo("@ 告白气球");

// ④ 官方统一入口 demandSend(类型, 平台, 名字, 作者, 播放地址, 封面, 原链接, 码率, 歌词)
demandSend(0, 0, "告白气球", "周杰伦",
  "https://music.163.com/song/media/outer/url?id=xx",
  "封面图URL", "s://music.163.com/#/song?id=xx", 128, "歌词");

// ⑤ 直接发送点播卡片（绕过 UI）
socket.send(JSON.stringify({
  m: "m__4@0>告白气球>周杰伦>封面图URL>6B5A4E>128",
  mc: "255,255,255",
  i: "id_" + Date.now()
}));
```

> `@@ 歌名` 直接请求并自动取第一首发到房间；`@ 歌名`（或 `@歌名`）打开搜索面板手动选。都要求媒体分享房间，关键词与 `@@`/`@` 之间空格可有可无。
> ⚠️ 往输入框**手动敲** `m__4…` 会被前端过滤加不可见前缀防伪造；用 `socket.send` / `demandSend` 不受限。分享文本格式 `<> url"名字"封面"作者` 由源码自动构造。

## 系统 / 认证（`$` 前缀）

| 命令 | 功能 |
|---|---|
| `$1` | 已有账号（有密码）打开用户设置面板时发送 |
| `$3+新用户名` | 修改用户名 |
| `$4+token` | 第三方登录 token 回调（Google OAuth、社交账号） |
| `$5+手机号` | 请求发送手机验证码 |
| `$6+验证码+手机号` | 提交手机验证码完成绑定 |
| `$700+验证码` | 微信扫码绑定：提交验证码 |
| `$701+0/1二进制串` | 设置推送通知偏好 |
| `$702` | 解绑推送/微信 |
| `$` / `$2` + `{JSON}` | 登录认证握手（进房时发送）：无密码 `$`+JSON、有密码 `$2`+JSON |

> `$?`/`$#`/`$^`/`$*`/`$!`/`$@`/`$%` 是接收端回包（见 [接收路由](md/websocket/messages.md)）。

## 投资/行情（`T` 前缀）

> 股票、加密币、A股行情**全部走 WS，没有 HTTP 行情接口**（HTTP 只有静态 logo）。三个面板共用同一套 `T` 协议：首字母 `k`/`e`/`a` 区分市场，第二位是子命令。
> ⚠️ 默认看不到这三个面板：对应侧边栏 `functionBtnDo(112/113/114)` 三个**隐藏按钮**，需自定义脚本（如 `functionBtnDo(113)` 或直接 `socket.send("Te#")`）才能调出。默认可见的「炒股」按钮（`functionBtnDo(9)`）打开的是**旧版 `stockOldHolder`**，数据走 `*` 房间载荷（见文末）。

| 市场 | 首字母 | 面板 | 按钮 `functionBtnDo` |
|---|---|---|---|
| 加密币 | `Tk` | cryptoHolder | `112` |
| 美股 | `Te` | stockHolder | `113` |
| 中国A股 | `Ta` | chinaHolder | `114` |

### 打开面板（请求全量行情）

```js
socket.send("Tk#");   // 加密币
socket.send("Te#");   // 美股
socket.send("Ta#");   // 中国A股
```

### 主动命令（`T` + 首字母 + 子命令）

> 以下 `{op}` 指 `Te`/`Tk`/`Ta`。`m` 开头为序号（本地自增），`c` 开头（仅加密币）为按 hash 的币，字段逗号分隔。

| 命令 | 功能 |
|---|---|
| `{op}#` | 重新请求行情列表 |
| `{op}g` | 签到（领花钞） |
| `{op}r{榜}` | 排行榜：`g`=盈利、`l`=亏钱、`w`=胜率、`a`=持仓货值 |
| `{op}p{币种},{周期}` | 请求 K 线：周期 `60`/`300`/`900`/`3600`/`86400`/`604800` |
| `{op}h{类}` | 历史记录：`o`=成交、`p`=期权 |
| `{op}v` | 请求交易统计 |
| `{op}z` / `{op}zu` | 订阅 / 取消成交动态流 |
| `{op}bm{seq},{币种},{数量}` | 现货买入 |
| `{op}em{seq},{币种},{数量}` | 现货卖出 |
| `{op}lm{seq},{币种},{多空},{数量},{杠杆}` | 合约开仓 |
| `{op}cm{seq},{仓位id},{数量}` | 合约平仓 |
| `{op}y{仓位id},{止盈},{止损}` | 设置止盈止损 |
| `{op}ds,{方向},{币种},{数量},{价格}[,杠杆][,止损]` | 限价委托：方向 `0`现货买/`1`现货卖/`2`融资买/`3`融券卖 |
| `{op}dc,{单id}` | 撤单 |
| `{op}as,m{seq},{币种},{方向},{目标价}` | 设置价格预警（`0`涨到/`1`跌到） |
| `{op}ad,{预警id}` | 删除价格预警 |
| `{op}om{seq},{币种},{多空},{金额},{期限}` | 二元期权押注 |
| `{op}tm{seq},{币种},{看涨跌},{行权%(K)},{期限s},{张数}` | 标准期权 |
| `{op}fs,{0活期/1定期},{金额}` | 存入理财（≥100 钞） |
| `{op}fr,{单id}` | 赎回理财 |

### 服务端推送解析

> 接收端按 `e[1]` 分发到对应面板，`e[2]` 为子命令、`e.substr(3)` 为数据体。字段多以 `"` 分隔条目、条目内逗号分隔。

| 子命令 | 含义 | 数据格式 |
|---|---|---|
| `S` | 市场状态 | `1`盘中、`2`盘前、`3`盘后、其它休市 |
| `#` | 全量行情列表 | 每条 `代码,名称,现价,昨收,价格精度,数量精度,今开[,涨停,跌停]` |
| `P` | 实时价格推送 | `代码"现价"昨收""今开` |
| `c` | 花钞余额更新 | 数字 |
| `H` | 持仓全量 | 每条 `代码,数量[,今日数量]` |
| `B`/`E` | 买入/卖出成交 | — |
| `O` | 合约仓位全量 | 每条 `id,方向,币种,数量,开仓价,杠杆,保证金,强平价[,资金费,止盈,止损]` |
| `L`/`C` | 开仓/平仓确认 | — |
| `!` | 实时爆仓 | `仓位id"币种"保证金` |
| `R` | 离线期间爆仓通知 | 多条 `仓位id,币种,保证金` |
| `K` | K线数据 | `代码"周期"` + `;` 分隔的 `开,高,低,收` 段 |
| `w`/`n` | 二元期权开/结算 | — |
| `Z`/`N` | 二元期权全量/离线通知 | — |
| `T`/`u` | 标准期权开/结算 | — |
| `U`/`M` | 标准期权全量/离线通知 | — |
| `G`/`g` | 签到状态/结果 | `G`:`今日已签,连续,奖励`；`g`:`奖励,连续,累计,余额` |
| `A`/`X` | 预警设置成功/删除 | — |
| `V`/`W` | 预警全量/触发通知 | — |
| `h` | 历史记录回包 | 类型 + 条目 |
| `Y`/`D` | 止盈止损更新/离线触发 | — |
| `F`/`x`/`i`/`j` | 限价委托挂单/撤单/成交/全量 | — |
| `S`/`I`/`J` | 理财存入/赎回/全量 | — |
| `Q`/`q` | 排行榜/今日战绩 | — |
| `v` | 交易统计回包 | 总盈亏/胜率/回撤等 10 项 |
| `z` | 成交动态流 | `A`开头=全量、`O`开头=实时单条 |
| `*` | 错误提示 | `"错误码` → 中文（`nosym`/`nohold`/`t1`/`climit`/`noorder`…） |

### 数据存储

- 行情对象：`Objs.{crypto|stock|china}Holder.Variable.coins[代码] = { name, coin(现价), prev(昨收), pd(价格精度), qd(数量精度), open(今开), up/dn(涨跌停) }`
- 自选收藏：localStorage `stockFav` / `cryptoFav` / `chinaFav`
- 面板 UI 记忆：localStorage `stockUI` / `cryptoUI` / `chinaUI`
- 涨跌颜色：`crUp`/`crDn`，齿轮可切换「红涨绿跌」
- 价格精度：`formatThousand`（千分位），美股 `≈$现价/180`、A股 `≈¥现价/25`

### 默认入口：「炒股」面板（stockOldHolder）

> `Te`/`Tk`/`Ta` 三个完整面板按钮被 `display:none` 隐藏，官方前端默认不可达。侧边栏「炒股」按钮（`functionBtnDo(9)`）打开的是**旧版 `stockOldHolder`**，这是当前唯一实际存在的股票功能。

**打开**：`functionBtnDo(9)` + `socket.send(">#")`。

**数据来源**：不走 `T` 协议，含在房间载荷 `%*` 推送里：`"` 分隔数据段、`#` 分隔银行/股票、股票再 `$` 分隔价格字段。

**命令**（`>` 前缀）：

| 命令 | 功能 |
|---|---|
| `>#` | 打开面板时请求股票数据 |
| `>%` | 手动刷新 |
| `>@数量` | 卖出 |
| `>$数量` | 买入 |

**限制提示**：
- 现价 <0.1 时买入被拒：「只有当股价大于等于0.1钞/股时，才可以购买」
- 卖出超持：「抱歉,您的持股量不足 !」
- 崩盘常驻横幅：「当股价跌至0钞时 , 您将会损失所有股票」
- 买入数量只接受整数

**`>` 前缀服务端推送**（同时承载股票 + 银行数据）：

| 推送 | 功能 |
|---|---|
| `>>持股量` | 卖出回包 |
| `><总金` | 买入回包 |
| `>%总金` | 更新总金 |
| `>*` | 股价 <0.1 不可购买提示 |
| `>#` | 股票崩盘 |
| `>!{数据}` / `>-{信用}` / `>${数据}` | 银行数据 / 信用 / 全量更新 |
| `>?$金额` | 存款成功 |
| `>?@金额` | 取款成功 |
| `>?!{活期 定期}` | 取款失败·存款不足 |
| `>?*{贷款 贷款 信用}` | 贷款失败·额度不足 |
| `>?&{贷款 贷款}` | 还款成功 |
| `>?^!` / `>?^#` | 取款/贷款超上限 |
| 其他 `>{银行}"` 包 | 股票+银行同包 |

> 买入/卖出校验失败时客户端会本地模拟回包（`><`/`>>`），显示与真实推送相同的提示。

## 用户状态（`@-` 命令）

在「状态」面板点选一项，客户端即向服务端发送 `@-{状态码}`：

**原始内容：**

```
@-1
```

**内容解析：**

```
@-(状态码)
```

| 状态码 | 状态 | 状态码 | 状态 |
|---|---|---|---|
| `n` | 无状态 | `8` | 睡觉中 |
| `0` | 会话中 | `9` | 上课中 |
| `1` | 忙碌中 | `a` | 作业中 |
| `2` | 离开中 | `b` | 游戏中 |
| `3` | 就餐中 | `c` | 看剧中 |
| `4` | 通话中 | `d` | 挂机中 |
| `5` | 移动中 | `e` | 自闭中 |
| `6` | 如厕中 | `f` | 请撩我 |
| `7` | 沐浴中 | | |

> 状态码 `0`~`f` 是十六进制（0~15），`n` 表示无状态。此命令由状态面板单选触发（`socket.send("@-"+码)`），与输入框里的 `@-`（游戏模拟器面板）是两回事。

## 其他前缀命令族

| 前缀 | 功能方向 |
|---|---|
| `~` | 弹幕（见上） |
| `&0` / `&1` + JSON | 播放媒体（见下节） |
| `%` | 请求歌单 |
| `{0`/`{1`/`{2`/`{3` + JSON | 媒体房切歌控制：`{0`切、`{1`切全部、`{2`切歌单、`{3`快进/快退 |
| `?` `?*` | P2P 信令交换：`?`+peerId、`?*`+房间id |
| `>` 系列 | 银行/旧股票面板命令（见上） |
| `p` `p=` `p-` | 私聊请求/离线消息：`p-@`来电应答、`p-*`去电请求 |
| `v1`/`v2`/`v3`/`vp`/`v23`/`v25` | v 系列扩展：私聊数据/帮助数据/手机绑定状态/充电支付/管理员帮助 |
| `m房间id` | 切房（见上） |
| `c` | 心跳（收到 `c` 后每 2 秒发一次） |
| `s` | 在线状态切换 |
| `r0` / `r1` | 用户列表刷新 |
| `o0` | 语言设置 |
| `@` `@-` | 快捷面板命令（见下） |
| `:` `:*` `:-` `:^` `:=` | 动态 / 论坛 / 任务 |
| `,` | 媒体 seek / 进度跳转 |
| `;` `;$` `;!` | 房间游戏命令：`;$`=游戏数据/购买、`;!`=游戏攻击 |

| `!` `!!` `!#` `!h3` | 房主管理命令（见下） |

`@` 快捷面板命令：`@`=媒体列表、`@+`=热推、`@)`=旧股票、`@.`=银行、`@-`=游戏模拟器面板、`@^`=财富榜、`@!`=留言、`@$`=商店、`@#`=用户搜索、`@]`=论坛、`@%`=任务、`@&`=动态、`@?`=帖子、`@(`=角色设置、`@=`=备忘录、`@~`=终端、`@;`=结缘、`@_`=骰子、`@*`=CP。

## 播放媒体（`&` 命令）

> 分享/播放媒体的直接通道（非点播卡片消息）。`&1`=视频分享房、`&0`=其他房。

**原始内容：**

```
&0{"s":"播放地址","d":215,"c":"封面","n":"名字","r":"作者","b":"@0","o":"原链接","l":"歌词"}
```

**内容解析：**

```
&0{"s":"(播放地址)","d":"(时长秒)","c":"(封面图)","n":"(名字)","r":"(作者)","b":"(平台标识)","o":"(原链接)","l":"(歌词)"}
```

`b` 平台标识：

| 值 | 平台 |
|---|---|
| `@0` | 网易云 |
| `@2` | QQ 音乐 |
| `@4` | 酷狗 |
| `!3` | B站视频 |
| `!8` | B站直播 |
| `=0` / `=1` | 通用音频 / 视频 |

```js
socket.send("&0" + JSON.stringify({
  s: "https://music.163.com/song/media/outer/url?id=xx",
  d: 215, c: "封面URL", n: "告白气球", r: "周杰伦",
  b: "@0", o: "s://music.163.com/#/song?id=xx", l: "歌词"
}));
```

> 切歌控制见命令族表 `{0-3` 行。

## 房主管理命令（`!` 前缀）

> 房间管理操作，参数为 JSON 数组字符串。来自 [iirosebot](https://github.com/XCWQW1/iirosebot) `api_iirose.py`。

**原始内容：**

```
!!["公告内容"]
!#["用户名"]
!h3["41","用户名","时长s","原因"]
```

**内容解析：**

```
!!["(公告)"]                                   → 发房间公告
!#["(用户名小写)"]                              → 踢人
!h3["41","(用户名小写)","(时长s)","(原因)"]      → 禁言
```

> `!h3` 变体可做全员禁言（同类 JSON 参数，enable 开关）。

## 论坛发帖（`:-` 前缀）

**原始内容：**

```
:-{"t":"内容","r":"消息id"}
```

**内容解析：**

```
:-{"t":"(内容，可带颜色前缀)","r":"(回复目标id)"}
```

> 非认证用户（游客）无法发送；`r` 为回复目标 id（回复时填），`t` 可拼颜色 + `[@回复id]`。

## Markdown 消息

消息内容以 `\\\*` + 换行开头即按 **Markdown** 渲染（接收端识别 markdown 前缀）：

```
\\\*
# 标题

**加粗**、`代码`

普通文本
```

- 代码块：`\\\*` + 换行 + ` ```lang ` + 代码 + ` ``` `
- 示例（iirosebot `api_message.py`）：`send_markdown(md)` = `f"\\\*\n{md}"`，`send_markdown_code(code, lang)` = `f"\\\*\n```{lang}\n{code}\n```"`
- 配合 `at_user(name)` = ` [*用户名*] `、`room_address(rid)` = ` [_{房间id}_] ` 可拼接
