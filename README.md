# IIROSE 前端逆向文档

蔷薇花园（iirose.com）前端逆向文档与还原源码。

## 文档

docsify 站点位于 [`docs/`](docs/) 目录，打开即浏览：

- 本地预览：`node serve.js` → http://localhost:3001/
- **GitHub Pages 部署**：Settings → Pages → Source 选择 **`main` 分支的 `/docs` 目录**

## 内容

- 应用架构（Electron 壳 + 网页双层结构）
- 登录认证 / 域名节点 / HTTP 接口大全
- WebSocket 协议（传输层 / 发送命令 / 接收路由）
- 核心功能（热推房间 / 地图 / 面板系统）
- 还原源码：`docs/reference/src/`
